# Code of conduct

This project follows the [Contributor Covenant, version 2.1][covenant].

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment,
insults and personal attacks are not accepted in issues, pull requests or any other project space.

To report a problem, contact the maintainer privately through GitHub (the profile of the repository owner), or use
the private vulnerability reporting described in [SECURITY.md](SECURITY.md) if it concerns a person's safety.
Reports are handled confidentially; the maintainer may remove content or block contributors who break these rules.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
