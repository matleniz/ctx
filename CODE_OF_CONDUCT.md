# Code of conduct

This project follows the [Contributor Covenant, version 2.1][covenant].

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment,
insults and personal attacks are not accepted in issues, pull requests or any other project space.

To report a problem, use the private vulnerability reporting form of this repository (Security tab, "Report a
vulnerability"): it reaches the maintainer only, and is fine for conduct reports too. You can also use GitHub's own
"Report abuse" on any comment or account. Reports are handled confidentially; the maintainer may remove content or
block contributors who break these rules.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
